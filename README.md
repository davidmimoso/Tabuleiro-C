## 🧩 Puzzle Solver em C

Implementação em C de um jogo de puzzle de tabuleiro baseado nas regras do **Hitori**.  
O jogador deve marcar casas como **brancas** ou **riscadas**, garantindo que não existem
letras repetidas em nenhuma linha ou coluna, e que as casas riscadas não são adjacentes entre si.
